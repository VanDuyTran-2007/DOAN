# Quy tắc làm việc với Git

- Remote chính của dự án: https://github.com/VanDuyTran-2007/DOAN
- Sau mỗi lần thực hiện thay đổi trong dự án, phải commit các thay đổi lên branch đang làm việc.
- Commit message cần ngắn gọn và mô tả đúng nội dung thay đổi.
- Branch chính của repository là `main`.
- Không commit các file/thư mục sinh tự động hoặc chỉ dành riêng cho máy cá nhân như `.vs/`, `bin/`, `obj/` và `*.csproj.user`.
